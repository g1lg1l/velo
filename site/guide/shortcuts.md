# Shortcuts

Every command has a key. On a Mac, read <kbd>Cmd</kbd> for <kbd>Ctrl</kbd> and <kbd>Option</kbd> for <kbd>Alt</kbd>. Press <kbd>F1</kbd> in Velo for this list, and <kbd>Ctrl</kbd> <kbd>K</kbd> to find any command by name.

The canvas's bare keys (<kbd>Tab</kbd>, <kbd>H</kbd>, <kbd>E</kbd>, <kbd>Delete</kbd>) act where the canvas has the keyboard or the pointer, so they don't get in the way of typing. Chords work whenever the window shows.

## Stage

The keys you play with.

| Key | Does |
|---|---|
| <kbd>1</kbd> to <kbd>9</kbd> | Launch scene 1 to 9 |
| <kbd>Space</kbd> (tap) | Launch the selected scene |
| <kbd>B</kbd> | Blackout |
| <kbd>F</kbd> | Freeze |
| <kbd>T</kbd> | Tap tempo |
| <kbd>L</kbd> | MIDI learn |
| <kbd>P</kbd> | Show or hide the preview |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>T</kbd> | Test pattern |

## Nodes

| Key | Does |
|---|---|
| <kbd>Tab</kbd> | Add a node |
| <kbd>H</kbd> or <kbd>Shift</kbd> <kbd>1</kbd> | Zoom to fit |
| <kbd>Shift</kbd> <kbd>2</kbd> | Zoom to selection |
| <kbd>Cmd/Ctrl</kbd> <kbd>F</kbd> | Find a node by name or kind: Enter goes to the next match, Shift Enter to the one before, Esc closes |
| <kbd>Shift</kbd> <kbd>0</kbd> | Zoom to 100 % |
| <kbd>Ctrl</kbd> <kbd>=</kbd> | Zoom in |
| <kbd>Ctrl</kbd> <kbd>-</kbd> | Zoom out |
| <kbd>Ctrl</kbd> <kbd>A</kbd> | Select all nodes |
| <kbd>E</kbd> | Turn the selection off or on |
| <kbd>Ctrl</kbd> <kbd>D</kbd> | Duplicate the selection |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selection |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>I</kbd> | Import an ISF shader |

## On the canvas

| Key | Does |
|---|---|
| <kbd>Esc</kbd> | Deselect |
| <kbd>Shift</kbd> click | Add to the selection |
| Double-click | Rename a node, or add one on empty canvas |
| <kbd>Space</kbd> drag | Pan (or drag with the middle button, or scroll) |
| <kbd>Ctrl</kbd> scroll | Zoom (or pinch) |
| <kbd>Alt</kbd> drag | Tie the cables the line crosses |

| <kbd>Ctrl</kbd> <kbd>J</kbd> | Show or hide the macros and sources |

| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>B</kbd> | Inspector in a window of its own, or docked |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>H</kbd> | Show or hide the frame times |
| <kbd>Ctrl</kbd> <kbd>I</kbd> | Show or hide the AI |

## Keyboard control

Velo works without a mouse too.

| Key | Does |
|---|---|
| <kbd>Esc</kbd> | Close a dialog |
| <kbd>Tab</kbd> | Next control (<kbd>Shift</kbd> for the previous) |
| Arrows | Move between controls |
| <kbd>Enter</kbd> | Press or toggle |
| <kbd>↑</kbd> <kbd>↓</kbd> | Turn a focused knob (<kbd>Shift</kbd> for fine steps) |
| <kbd>Delete</kbd> | Reset a focused knob |
